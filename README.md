# PURPLE COURIERS

### A Digital Package Tracking & Receiving System

Purple Couriers is a courier service that allows customers in Jamaica to shop online using a Purple Couriers shipping address.

The customer purchases an item from an online store and uses their assigned Purple Couriers address as the delivery address.
The online retailer then sends the package to the Purple Couriers facility.

The problem is what happens **after the package reaches the courier facility.**

Currently, there is no structured digital stock-taking system that clearly records when a package is received, who it belongs to, and what happens to it afterward.

### THE SOLUTION

Purple Couriers should have a website and mobile-friendly application that creates a digital record for every package.

The system will have **two sides:**

### 1. CUSTOMER SIDE
Customers will have their own account where they can upload their receipt or order information. The receipt contains:
* Customer name, Online store, Order number, Tracking number, Items purchased, Expected delivery information

Once the package reaches the Purple Couriers facility, staff update its status and the customer receives a notification.

### 2. PURPLE COURIERS BUSINESS SIDE
The business dashboard should provide a simple overview of every package.
Employees should be able to:
* ADD PACKAGE
* SCAN PACKAGE
* SEARCH PACKAGE
* CONFIRM RECEIVED
* UPDATE STATUS
* MARK FOR SHIPPING
* MARK ARRIVED IN JAMAICA
* MARK DELIVERED

### THE PACKAGE JOURNEY
1. CUSTOMER PURCHASES -> 2. CUSTOMER SUBMITS RECEIPT -> 3. PACKAGE IS DELIVERED -> 4. PURPLE COURIERS RECEIVES PACKAGE -> 5. CUSTOMER IS NOTIFIED -> 6. PACKAGE IS PREPARED FOR SHIPPING -> 7. PACKAGE ARRIVES IN JAMAICA -> 8. CUSTOMER RECEIVES PACKAGE

### THE MAIN PURPOSE
Purple Couriers isn't simply building an app. It is building a **package accountability system.**
The goal is to know: What package is this? Who does it belong to? When did we receive it? Who received it? Where is it now? Has it shipped? Has it arrived in Jamaica? Has the customer received it?
